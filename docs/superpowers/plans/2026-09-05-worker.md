# Worker Implementation Plan

**Goal:** Запускаемый Linux/WSL2 worker с локальной проверкой FaceLift.
**Architecture:** Один GPU slot, постоянные модели, независимый heartbeat, SQL/S3 adapters.
**Tech Stack:** Python 3.10, psycopg 3, boto3, Pillow/HEIF, существующий FaceLift.
**Spec:** ../specs/2026-09-05-worker-design.md

## Ограничения

Контракт worker_api/v1; этапы и fencing строго из worker-interface.md.
FaceLift — отдельный Git repository. Не менять backend и не развёртывать сервис.

## Выполнение в текущей сессии

1. Написать `tests/test_runtime.py`: success, cancel, lost lease, failure,
   heartbeat during blocked engine, ambiguous complete. Запустить
   `python -m unittest discover -s tests -v`, подтвердить отсутствие реализации.
2. Реализовать `runtime.py`: `run_attempt(db, storage, engine, assignment, root)`;
   `LeaseGuard` сериализует heartbeat и terminal SQL calls.
3. Написать тесты streaming limits и SQL argument binding; реализовать
   `storage.py`, `database.py`, `config.py` и цикл LISTEN/reconnect.
4. Добавить необязательные параметры `on_stage`, `check_cancel`, `ply_only`
   в `process_single_image`; прежний CLI сохраняет поведение. Написать CPU
   проверки API через AST, реализовать FaceLift adapter и local CLI.
5. Добавить pyproject, .gitignore, .env.example, install script, systemd example
   и README с командами для Linux/WSL2 и двух отдельных repositories.
6. Запустить unittest, compileall, CLI help; проверить diff и отсутствие секретов.
   Зафиксировать ограничения GPU/WSL и отсутствующего backend в README.

## Результат проверки, 2026-09-05

- Реализованы все перечисленные файлы, CLI, адаптеры и режим PLY-only.
- `scripts/install.sh worker-only` выполнен в Ubuntu 22.04 WSL2, Python 3.10.12.
- 31 CPU-тест прошёл без пропусков, включая JPEG/PNG/HEIF и Linux flock cleanup.
- `ruff check metology_worker tests`: passed; `pip check`: no broken requirements.
- Установленная команда `metology-worker --help` работает.
- `doctor` ожидаемо возвращает ненулевой код: отсутствуют nvcc, ffmpeg, GPU
  зависимости и два checkpoint. Реальный PLY и сквозная job ещё не проверены.
- Независимое ревью выявило три ошибки обработки SQL-сбоев; они исправлены
  с regression tests, повторное ревью исправлений замечаний не выявило.
